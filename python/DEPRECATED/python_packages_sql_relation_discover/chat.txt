project-sql/ репозиторий с sql файлами


Input SQL files live at:
`{project}-sql/sql/_shared/SCHEMA/{schema}/TABLE/{table}.sql` - включаем только внутри _repl_tasks схем
`{project}-sql/sql/SCHEMA/{schema}/TABLE/{table}.sql` - включаем ВСЕ

Output Python files must be created at:
`{project}-python-packages/packages/{schema}/{schema}/_init__.py`
`{project}-python-packages/packages/{schema}/{schema}/models/_init__.py`
`{project}-python-packages/packages/{schema}/{schema}/models/{table}.py` ПУСТОЙ ФАЙЛ, будет потом сгенерирован ИИ



формат файлов:
`{project}-python-packages/packages/{schema}/{schema}/models/_init__.py`
импорты из `{project}-python-packages/packages/{schema}/{schema}/models/*.py (а значит __init__.py надо генерировать в последнюю очередь)
импорты должны быть построчно 1 строчка на 1 модель
from .{filename} import Xxx

правило для генерации имени модели:
<rule>
EXCEPTION: if the SQL table name ends with the literal suffix `_queue`, then:
- Remove the `_queue` suffix.
- Convert the remaining part to PascalCase using rule 1.
- Append the suffix `Task` (NOT `Queue`).
Example pattern (do NOT copy literally):
`word_word_queue` -> `WordWordTask`
`word_queue` -> `WordTask`
</rule>
